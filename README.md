California Housing Dataset

Project Overview

The California Housing Dataset contains information about housing properties and demographic characteristics across different regions of California, USA. This dataset is used for data analysis and machine learning projects to understand the factors that influence house prices.

Dataset Information

- Total Records: 20,640
- Total Columns: 10
- File Format: CSV
- Target Variable: median_house_value

Features Included

1. Longitude: Geographic longitude of the location.
2. Latitude: Geographic latitude of the location.
3. Housing Median Age: Median age of houses in the area.
4. Total Rooms: Total number of rooms.
5. Total Bedrooms: Total number of bedrooms.
6. Population: Total population of the area.
7. Households: Number of households.
8. Median Income: Median income of households.
9. Median House Value: Median house value (target variable).
10. Ocean Proximity: Distance or proximity category to the ocean.

Project Objectives

- Explore and understand the housing dataset.
- Perform data cleaning and preprocessing.
- Analyze relationships between housing features and house prices.
- Visualize important patterns and trends.
- Build a machine learning model to predict house prices.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Expected Outcome

To understand the major factors affecting California housing prices and develop a machine learning model that can predict median house values based on the available features.
